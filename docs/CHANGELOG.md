# 変更履歴

## 0.4.0（2026-10-20）

### 互換（更新する前に）
- **新しいプロジェクトは、フォルダ構成（`data/projects/<名前>/project.csv` ほか）で作られます。0.3.x では開けません**（0.4.0 から 0.3.x に戻すときは、`project.csv` を取り込み直してください）
- 0.3.x までの平置きのデータ（`<名前>.csv`）は、動かさずにそのまま読み書きできます。フォルダ構成に移すかどうかは、「アプリの設定」の「フォルダ構成に移す」で選べます（移す前に全ファイルを控えます）
- Windows の実機では、ファイルのドロップ・添付を開く・画像のサムネイル・クリップボード・日本語入力・高DPI は未確認です（CI の成果物で動作の確認をお願いします）


### 課題の作成
- アプリの設定に「課題を追加したとき、親や直前の兄弟の値を引き継ぐ」（既定はオフ = 今までどおり）。「子を追加」は親から、「同じ階層に追加」は直前の兄弟から、担当者・優先度・ラベル・期限（兄弟からは種別・期間も）を項目ごとに選んで引き継ぐ。種別は設定に関わらず階層で決まる。追加直後の通知「親から引き継ぎました（元に戻す）」から、追加ごと Undo 1回で戻せる。担当者を引き継ぐと担当者ごとの負荷が偏るので、設定の説明に注意を書いた
- 親の名前が見えない場面で、祖先のパス（`A › … › B`。長いときは真ん中を省略）を薄く出す: その場編集中の入力欄の上、並べ替え中の平らな一覧の件名の右（行の高さは変えない）、詳細パネルの見出し（これまでどおり押すとその課題へ移動。長いときは真ん中を「…」にしてマウスを載せると全体を出す）
- アプリの設定に「新しい課題の名前」を追加: 今のまま（既定）／親の名前＋連番（`要件定義の子 3`）／親の名前／既定名／自由入力（`{親}` `{親ID}` `{n}` `{日付}`）。入力欄に最初から入り、追加直後の Enter（次の行）でも付く。連番は兄弟の名前と重ならない。最上位は `新しい課題 n`。設定は `roadmap_prefs.json` の `newNameFormat`・`newNameCustom`
- 親の課題を1つ選んで `Ctrl+V`（入力欄の外）: クリップボードの複数行を、子課題としてまとめて作る。階層はインデント（タブ・空白・全角スペース・`- `・番号付きの箇条書き）で決め、タブ区切り（Excel）は1列目を件名にする。確認のプレビュー（件数・階層・先頭の12行・丸めた箇所の警告）を出し、上限は500行、Undo 1回で戻る。コマンドパレットからも使える

### 統計ビュー
- 5つ目の表示「統計」（キー `5`・コマンドパレット）。進み（期間ベース）・作業の件数・遅れ・余裕小・完了の見込み・担当なし、状況の積み上げ棒、余裕の分布、週ごとの完了（過去は完了日、先は最早の完了日）、担当別、ルート課題別、優先度別。絞り込みには従わず、プロジェクト全体を数える。担当別の行を押すと、その担当者の作業をリストで開く
- 集計は `core/stats`（UI に依存しない）。単体テストを足した

### 雛形
- 新しいプロジェクトと「はじめに」に「組込みソフトウェア開発の雛形」（要求・企画 → システム設計 → 詳細設計・実装・単体テスト → 結合・システムテスト → リリース・量産移管。42件、マイルストーン4つ。日付は持たず、作った日を基準に積む）。実行ファイルに埋め込む。件名・期間・依存は自分のプロジェクトに合わせて書き換える

### 依存
- 詳細パネルの「依存関係」タブの入力欄に候補一覧を出す（表示ID・キー・件名の部分一致。完全一致 → 最近つないだ課題 → 同じ階層の課題を先頭に）。クリック、または ↑↓ と Enter で選ぶ。追加済み・自分は出さず、循環になる相手と親子は理由つきで選べない表示にする
- 「画面で選ぶ」ボタンと、右クリックメニューの「先行にする…」「後続にする…」で、一覧・ガント・ボードの行（カード・バー）をクリックして相手を選ぶモードに入る（Esc か「中止」で抜ける）。つなげない相手は理由を通知して続ける。Undo 1回で戻る
- 複数選択して、右クリックのメニューと選択バーの「順につなぐ」「つなぎを外す」。画面の表示順（一覧・ガント・ボードのどこからでも）に A→B→C と終了→開始でつなぐ。親子の両方を選んだときは親だけ数える。すでにあるつなぎは足さず、循環になるときは何も変えずに理由を通知する。1回の Undo で戻る（ショートカットキーはなし）
- ガントのバーにマウスを載せると左右の端にハンドルが出る。右のハンドルから別のバーへドラッグで後続、左なら先行。ゴムひも線・吸着・つなげない相手（循環・重複・親子）は赤で理由・日程への影響のゴースト（「◯が N営業日 遅れます」）。離すと確定（Undo 1回）、空きで離すか Esc で取り消し（#8）
- 依存の矢印: ホバーで強調（「A → B」）・衝突（後続が先行の完了より前）は赤の点線・「依存 ▼」から「たどる」（選んだ課題の先行・後続以外を薄くする）と「クリティカルを強調」・矢印をつかんで付け替え、バーのない場所で離すと削除（#10）
- リストとガントの左の表に任意の「先行」列（設定でオン・オフ。既定はオフ）。ダブルクリックで表示 ID をカンマ区切りで入力し、存在しない・あいまい・重複・自分自身・親子・循環は赤で理由を出して確定しない。差分だけを反映（Undo 1回）、並べ替え・列の漏斗に対応（#9）
- 詳細パネルの「依存関係」タブの下に、Blocks 以外のリンク（Relates など）を「日程には影響しません」として表示・追加・削除（値は今までどおり知らない列に入るので、CSV の往復は変わらない）（#12）

### 保存（フォルダ構成）
- 新しいプロジェクトは `data/projects/<名前>/project.csv`・`project.settings.json`・`バックアップ/` で作る（CSV のバイト列は同じ）。削除は `_削除済み/<名前>.<日時>/` へフォルダごと。バックアップの30個はプロジェクトごと。フォルダの監視は1段下まで
- 以前の平置きは動かさず、そのまま読み書きできる。「データフォルダ」と「アプリの設定」の「フォルダ構成に移す」で、移す前に全ファイルを控え、バイト列を変えずに写して確かめてから元を消す（失敗したら元を残す）（#24）

### 添付
- 課題にファイル・画像を付ける。置き場は `<プロジェクト>/添付/<Issue Id>/`。詳細パネルの「添付」タブ（一覧・開く・削除・使用量）、行・ガント・カードにクリップと数。エクスプローラーから課題の行・カード・詳細パネルへドロップで添付、何もない場所は今までどおり CSV の取り込み。1ファイル 50MB・合計 1GB まで。削除は `_削除済み/<Issue Id>/` へ。実行ファイルは開く前に警告
- PNG・JPEG・GIF・BMP のサムネイルとプレビュー（`stb_image` 2.30 を `third_party/stb` に同梱。パブリックドメイン／MIT・ヘッダ1つ・ネットワークなしでもビルドできるため）。JIRA の Attachment 列は、取り込み・書き出しで壊さず、添付タブに「本体はありません」と表示（#19）

## 0.3.0（2026-10-20）

### 拡大縮小
- 画面全体: `Ctrl+ホイール`（タッチパッドのピンチも同じ）・`Ctrl+「+」「-」`・`Ctrl+0`（100%に戻す）。70〜200% の9段階で、変えた値は設定ファイルに保存する。変えた直後に倍率を画面の上に出す。アプリの設定にも「-」「+」「100%に戻す」を置いた
- ガントの時間軸: 時間軸の上で `Ctrl+ホイール` を回すと、1日の幅を連続して変える（0.9〜40px）。マウスの位置の日付が動かない。日・週・月・全体のボタンを押すと段階に戻る。幅は保存しない（JS版と共有する設定に、JS版が知らない値を書かないため）

### 配布
- インストーラ版（`ProjectRoadmap-Setup-<版>.exe`。Inno Setup）を CI で作り、リリースに付ける。既定は管理者権限なし（`%LOCALAPPDATA%\Programs\ProjectRoadmap`）、「すべてのユーザー」も選べる。日本語・英語の画面、スタートメニューとデスクトップのショートカット。上書きインストールで更新でき、アンインストールしても `data\projects` と `roadmap_prefs.json` は残す。CI で無人のインストール・上書き・アンインストールまで確かめる
- ポータブル版の zip はこれまでどおり

## 0.2.0（2026-10-20）

### 画面
- 上のバーの絞り込み（担当・状況・優先度・「遅れ」「余裕小」のチップ）は、一致しない課題を消さずに薄く表示する。検索語はこれまでどおり隠す
- 表の列名（課題・種別・状況・担当・優先度・余裕）の右に漏斗を置き、値のチェックで列ごとに絞り込む（一致しないものは隠す）。件名は文字で絞り込む
- 行（ボードはカード）にマウスを載せると、ごみ箱のボタンが出る。押すとすぐ削除し、通知の「元に戻す」で戻せる
- 「アプリの設定」（`…` メニュー・`Ctrl+,`・コマンドパレット）: 保存先の変更と既定に戻す（今のプロジェクトのコピーを選べる）、テーマ・密度・文字の大きさ（90〜150%）・絞り込みで薄くする濃さ、自分の名前、削除の前の確認、ヒントをもう一度表示、設定ファイルの場所。テーマと密度はプロジェクト設定からこちらへ移した
- アプリの設定に「プロジェクトを開いたら基準日を今日に合わせる」（起動中、プロジェクトごとに1回。前の日付は通知に出す）
- データフォルダを監視し、Excel などで CSV を保存・追加したら、ウィンドウがアクティブでなくても0.5秒後に取り込む（編集中は終わるまで待つ）
- 「N」で行を追加した直後など、入力欄がアクティブになる前に打った文字も落とさない（B13）
- 「削除の前に確かめる」をオンにすると、ごみ箱・Delete キー・メニューの削除で確認ダイアログを出す（子の件数も表示）

### 配布
- ポータブル版のフォルダ構成（exe・`data/projects/`・`samples/`・`README.txt`）を `cmake --install --component portable` で作る。CI の成果物とリリースの zip もこの形

### CI・依存
- Windows（MSVC）のビルドが通るように直した（CMake 4 と doctest、`windows.h` の `max`）。警告をエラーにし、UI の煙テストも動かす
- doctest を 2.5.3 に更新（CMake 4 で警告なく構成できる。テストだけで使う）

## 0.1.0（2026-10-19）

SPEC 第13章の P0〜P7 を一通り実装した最初の版。

### P0 環境
- リポジトリの骨格、CMake（プリセット: windows-release / linux-asan / linux-ui / mingw-cross）、依存の版の固定（FetchContent）
- GitHub Actions（Linux: GCC・Clang + ASan/UBSan、UI の煙テスト、Windows: MSVC で exe とテスト）
- UI スパイク: ImGui を暫定採用。Windows 実機での確認が残る（[ui-spike.md](ui-spike.md)）

### P1 日付と CSV
- 営業日カレンダー、日付の読み取り（3つの書式）、期間の読み取り、コメント
- CSV の字句解析（区切りの自動判定・引用符・改行）、見出しの同義語、未知の列の保持、JIRA用の階層の畳み込み
- 文字コード: UTF-8（BOM可）→ Shift_JIS（CP932）→ 置換。書き出しは BOM なし UTF-8・CRLF
- golden: 3サンプルの `roundtrip.csv`・`jira.csv` がバイト一致

### P2 エンジン
- ツリー構築（親ループ・依存ループの検出、親への依存の展開、期限の継承）、最早・最遅・余裕、親のまとめ、シナリオ、担当者ごとの同時作業の制限、負荷
- golden: 計算13ケースが全フィールド一致。5,000件で約5ms（制限ありで約40ms）
- 性質のテスト（往復・Undo・不変条件・単調性・フィルタ）

### P3 編集・保存・テンプレ
- `Session`（mutate・Undo/Redo 100件・まとめての操作）、9.2 の全操作、テンプレート（番号タグの採番）
- 絞り込み（10.8）、データフォルダ（原子的な書き込み・バックアップ30個・_削除済み・外部変更の3ケース・不正なCSVを上書きしない）
- settings.json・共有/バックアップJSON・roadmap_prefs.json（未知のキーを保持）

### P4 CLI
- `rmcli schedule / import-export / check-jira / gen / validate`。出力は golden とバイト一致

### P5〜P7 アプリ
- AppController（選択・絞り込み・保存の予約 400ms・再試行 2→5→10秒・アクティブ時の同期）
- ガント・ボード・リスト・ギャップ・ゴールのポップオーバー・詳細パネル・コマンドパレット・全ダイアログ・通知・まとめ編集バー・はじめに
- Win32: 高DPI・IME・日本語フォント（足りない字は作り直して追加）・ファイルのドロップ・ダイアログ・終了時の確認・ダーク/ライト
- 単一 exe（MinGW のクロスビルドで 3.5MB、システムDLLのみ）
- GitHub Actions の windows-latest（MSVC 19.51・/MT）でビルドとテスト 25 件が通る。exe は 1.9MB
