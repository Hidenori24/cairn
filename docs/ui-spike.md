# UI の採用経緯と確認範囲

## 採用した構成

Dear ImGui + Win32 / DX11 を採用して公開しています。初期のスパイクで候補を比較した記録を引き継ぐ文書です。UI フレームワークの選択は完了しており、現在の問題は個別の Issue として扱います。

## Windows 実機での確認

v1.0.0 公開前の利用者による確認は [#83 のチェックリスト](https://github.com/Hidenori24/cairn/issues/83) に記録されています。

- インストール・上書き更新・アンインストールでのデータ保持、ポータブル版。
- IME（その場編集・検索・パレット・ダイアログ）、高 DPI（125／150／200%）と異なる解像度のモニター間の移動、テーマ・密度、5,000件での操作。
- ドロップ・ファイル選択・クリップボード・添付のプレビュー・リンクを開く・外部 CSV の変更取り込み。
- 任意の `gh` による状態確認、HTML の印刷と週報。

**共有ドライブ2台（SMB）での確認は未実施で、利用者の判断で今回の確認対象から外しています。** チェックリストの完了は fps・フォント読み込み時間の定量測定ではなく、Windows の全バージョン・全 IME の組み合わせを保証するものでもありません。Windows の具体的な版・IME の種類など、チェックリストに記録のない条件は確定できません。

v1.1.0 の本文サイズ・上部2段・倍率メニューについては、以下のヘッドレスの確認を追加しています。v1.0.0 での実機確認と、この版の全組み合わせの実機確認は区別します。

v1.3.2 では、利用者が PR #134 の Windows 版 exe を手元で確認しました。確認した環境や個別の操作結果の記録はないため、ほかの Windows 環境まで確認済みとは扱いません。

## 開発環境と CI で確認すること

| 環境 | 確認する範囲 | 範囲外 |
|---|---|---|
| Linux・ヘッドレス（`app/tests/ui_smoke.cpp`） | ImGui を GPU なしで動かし、ビュー・ダイアログ・編集・パレット・5,000行など。CI は ASan / UBSan 付き | 実際の Windows の IME 候補・DX11・モニター移動 |
| Linux・ソフトウェア描画（`app/tests/ui_screens.cpp`） | Noto Sans CJK で画面例を生成し、配置・色・文字の欠けを確認 | Windows フォントの見え方・実機の fps |
| Windows / MSVC（CI） | ビルド・単体テスト・ヘッドレス UI・インストーラの無人確認 | 人の操作による実機の表示・入力の確認 |
| 過去の Wine 9.0 + Xvfb | 当時の MinGW 版（旧名 `ProjectRoadmap.exe`）で起動・クリック・その場編集・保存・Ctrl+K | 現行版の Windows 実機の代わりにはならない |

実装はシステムフォントを Yu Gothic UI → Meiryo UI → MS UI Gothic の順に探索し、画面・データの字形を追加します。IME の候補位置は Win32 バックエンドで調整し、変換中・確定直後の Enter が編集の終了や追加を起こさないようにしています。DPI は PerMonitorV2 と `WM_DPICHANGED` に対応します。

## v1.1.0 の配置・倍率の確認

`roadmap_ui_smoke --ux` は960〜1440px相当・標準／コンパクト・100／150%での配置、レポートの入口、計画の「今日にする」、条件の個別解除と折り返しを確認します。

`roadmap_ui_smoke --readability` は倍率の選択と保存、4K相当で DPI 150／200% × アプリ100／125／150／200%の組み合わせを確認します。本文15px・見出し20pxを基準にフォントも作り直し、標準／コンパクトで配置を確認します。

`ROADMAP_SHOT_ONLY=ux roadmap_ui_screens <出力フォルダ>` は通常・条件付き・960px・レポート・計画・ダーク、`ROADMAP_SHOT_ONLY=readability` は標準・倍率メニュー・4K相当の画面例を出力します。先に出力フォルダを作成してください。

## 今後、実機で確認するときの手順

1. 対象版と Windows の版・IME・DPI・モニター数を記録します。テスト用の保存先を使います。
2. 件名を編集して日本語を変換し、候補表示・確定・取消と、確定の Enter で課題が増えないことを確認します。
3. Windows 125／150／200%とアプリの倍率を変え、別のモニターへの移動後も文字と操作が収まることを確認します。
4. `rmcli gen --count 5000 -o big.csv` を取り込み、スクロール・ガントの拡大縮小・ドラッグを確認します。性能を比較するときは PC と測定条件も記録します。
5. 「PDF を保存…」で開ける PDF ができ、選んだガントの用紙幅と、ほかの節の A4 縦が反映されることを確認します。HTML を印刷するときもプレビューでページ幅と改ページを確認します（[使い方](GUIDE.md#html週報pdf)）。

不具合は個別の Issue に、環境・操作・期待した結果・実際の結果を記載します。
